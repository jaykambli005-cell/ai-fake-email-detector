AI Fake Email Detector

Project Overview

The AI Fake Email Detector is a web application developed using Python and Flask to identify suspicious emails and potential phishing attempts.

Objectives

* Detect potentially fraudulent emails.
* Identify suspicious words and links.
* Display email analysis results.
* Help users recognize potential email threats.

Technologies Used

* Python
* Flask
* HTML
* CSS
* SQLite
* Machine Learning (if implemented in the project)

Main Features

* User registration and login
* Email analysis
* Suspicious email detection
* Risk classification
* Email checking history

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required Python packages.
4. Run the application using:

python app.py

5. Open the local address displayed in the terminal in your web browser.

Conclusion

This project aims to help users identify suspicious emails and improve awareness of phishing threats.
